# Baratao.mais - Aplicativo Web de Postos de Gasolina

Aplicativo web responsivo e moderno para a rede de postos Baratao.mais, oferecendo aos usuários a facilidade de encontrar postos, consultar preços e aproveitar ofertas especiais.

## 🎯 Funcionalidades

- ✅ **Busca de Postos**: Encontre postos próximos digitando cidade, bairro ou CEP
- ✅ **Preços em Tempo Real**: Consulte os preços de gasolina, etanol e diesel
- ✅ **Ofertas Especiais**: Acompanhe as melhores ofertas disponíveis
- ✅ **Design Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- ✅ **Animações Suaves**: Experiência visual agradável com scroll animations
- ✅ **Conveniência Completa**: Informações sobre serviços e conveniências
- ✅ **Contato Direto**: WhatsApp e Instagram integrados

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/danielrodrigues0109-a11y/baratao-mais-app.git
```

2. Navegue até o diretório do projeto:
```bash
cd baratao-mais-app
```

3. Abra o arquivo `index.html` em seu navegador:
```bash
open index.html
```

Ou use um servidor local:
```bash
python -m http.server 8000
# Acesse http://localhost:8000
```

## 🛠 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Layout Grid/Flexbox, animações, responsividade
- **JavaScript**: Interatividade, busca de postos, smooth scroll
- **Intersection Observer API**: Animações ao scroll
- **Typography**: Montserrat (Títulos), Inter (Textos)
